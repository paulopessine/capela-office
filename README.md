## Sobre o projeto

O Projeto Capela Office representa o desenvolvimento completo de uma infraestrutura de redes para um ambiente corporativo de pequeno porte.

Todo o projeto foi planejado, documentado e validado antes da implantação física.

Este repositório reúne gratuitamente toda a documentação produzida durante o desenvolvimento.
